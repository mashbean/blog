Code for Japan、DigDAO 和澀谷區（Shibuya ward ）發表了平方資助實驗平台，其目標為促進數位公共財生態系發展，特別是公民科技專案。這項專案將以民主化的分配方法，將資金分配給各個數位公共財專案，這些專案過去在傳統政府採購案與獎助案中並不容易獲得資源。

關於數位公共財（Digital Public Goods, DPG）

根據聯合國定義，數位公共財包含開源軟體、開放資料、開源 AI 模型、開放資料標準和開放內容，這些項目都有益於永續發展目標（SDGs）。而這次平方資助的專案目標是將資源挹注給有公共利益的數位專案，解決社群與社會問題，尤其是開源軟體和開放資料類別的議題。

日本數位公共財的背景

Code for Japan 一直積極推動公民科技，比如說公民使用科技手段來解決社群問題。儘管 Code for Japan 曾誕生許多成功專案，但他們還是得面對財源不穩定的問題，尤其是沒沒無聞的小專案更是如此。Code for Japan 從以太坊（Ethereum）生態系中不同的平方資助專案、聯合國兒童基金會創新辦公室（UNICEF OOI）和台灣數位發展部（註：為公益創新．徵案100專案）的實驗中獲得養分，因此決定嘗試這種為數位公共財募集資源的方法。

平方資助概述

平方資助法是一種基於捐款數量和金額大小的民主化資助機制。與傳統的群眾募資不同，群眾募資的單一捐款金額將直接資助專案，而平方資助則根據捐款人數和捐款金額增加分配資金。這使得許多人支持但小額的捐款，讓專案獲得更多的資金。

Code for Japan 的 Hal Seki 評論

「Code for Japan 一直支持許多公民科技專案，並為創建開源軟體和開放資料做出許多貢獻。然而確保這些專案取得資源一直是個挑戰。這個新的配捐平台是一種將善心轉化為資金的永續機制。我們希望許多專案和捐贈者能參與這場行動，共同建設更美好的未來。」

未來展望

未來，Code for Japan 將與政府和基金會合作，取得更大的公共資金，支持更多元的數位公共財生態系。我們的目標是讓公民主導的專案得以永續，繼而解決社會問題。

作為專案負責人的個人意見

僅供參考：我在 15 歲時創立 Civichat，這是一種用於尋找合適公共福利服務的聊天機器人，不過這個服務作為數位公共財，無法盈利。現在我作為公民駭客，終於能為公共財生態系的未來做一點貢獻，包括 Plurality Tokyo、DigDAO 和 Funding the Commons Tokyo 等等。

這個專案實際上是從 Gitcoin 的法定貨幣平方資助開源軟體服務（Web2 QF OSS ）分岔出來的。它就像一個群眾募資平台，但從技術專業的角度而言，是以平方資助為方法進行分配。我與政府或非營利組織的人一起花了幾年時間做好這個專案，向多元共榮的世界邁向一大步。

對我們說，以太坊生態系（有些人稱之為 web3）已經以平方資助為方法分配了數千萬美元的公共資金。但主權國家的政府（幾乎所有自由意志主義者都討厭這個！！）仍然是基於官僚思維進行的中心化的資源分配。

我們可以在台灣看到類似的實驗。他們以主權國家邁向民主但仍在努力。歐盟一些地區正在嘗試以「參與式預算」來分配預算，但日本還沒有，不過此時澀谷區加入了我們。未來也許我們可以通過政府，將實驗變得更大和更多。

以太坊是一個開源軟體平台。有很多實驗正在進行。我們可以做超越以太坊的事情，為下個十億人進行努力。

格里夫．格林（Griff Green）提到我們可以在政府中找到巨大的市場。一些社群正在嘗試這樣做，例如 Metagov、集體智慧專案（Collective Intelligence Project）和 g0v。

最後，讓我分享我最喜歡的一句話：「不要問為什麼沒有人做這個，因為你就是沒有人！」by g0v
