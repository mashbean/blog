# mashbean-blog Typora theme

這個 theme 依照 blog 目前文章頁的視覺 token 製作，主要對齊以下元素：

- 暖白紙色背景與淡青綠點綴
- `Noto Sans TC` 正文、`Noto Serif TC` 標題、`JetBrains Mono` 程式碼
- 約 `74ch` 的文章寬度
- H2 serif 標題、H3 左側 accent 線
- blog 同系的 blockquote、inline code、dark code fence、table 與圖片邊框

## 安裝

macOS 的 Typora theme 目錄通常在：

```text
/Users/mashbean/Library/Application Support/abnerworks.Typora/themes/
```

把 `mashbean-blog.css` 複製到上面的目錄後，重新開啟 Typora，從 `Themes` 選單切到 `mashbean-blog` 即可。

## 備註

- 這個 theme 會透過 Google Fonts 載入字體；如果 Typora 當下無法連網，會退回 `PingFang TC` / `Microsoft JhengHei` / 系統等價字體。
- Typora 本身的 UI 結構和 blog 前端不同，所以這份 theme 是對齊「文章閱讀區」而不是整個網站 header / sidebar。
