我是一個很熱愛做簡報的人，雖然不是什麼可以開簡報課那種的道行，但我非常注重排版的協調以及分享時演講、語調與畫面之間的互補，光是這樣東改西改就讓我自得其樂。

不過 Claude Design 的出世後，我實在非常感謝它，讓空有簡報魂但這年頭忙忙忙的我，再次進行了解放。

以前在醫院做簡報，撇除可以快速專業溝通的白片，一份好簡報我都抓大概 15 小時（到底誰有 15 小！），可以讓畫面與折線圖等等的超美。

後來出社會、轉行後發現原則也差不多，但因為不同場合用簡報的需求差異實在太大，就不太追求美觀，而是符合不同人士的期待。比如公部門喜歡塞很多字，因為有些長官沒看到字就不知道要講什麼（而且許多簡報是跨單位先行做功課的基底，反而不應叫簡報）。喔我所謂的美觀不是花俏的排版，而是能夠在表達上令人印象深刻。

後來更懶，但凡遇到相同主題的分享，就用 keynote 反覆修改舊簡報拿來用，那就純粹的各種圖片與標題的致用型簡報了。

但用了 Claude Design 之後，我發現美感與速度可以兼具，而且越用越上手。

比如說由於下週有五場演講，而且有三場需要先與不同同場講者對過，不只是演講用簡報而已。所以我花了大概三小時的時間，把不同已經準備好的素材，跟初步寫的大綱，以及不同講者的背景，混作灑尿牛丸，做成三份簡報。

三個小時！！！就做好三份幾乎可以直接用的簡報，而且風格各異。

其中一份由於我已經做好了整個企業識別的 design system，所以一鍵從 github 套用色票、字型、版型，整個美觀到不可思議；另一份簡報採用活動標準色，並且自動套用了瑞士系統與粗獷主義的混合，我只跟他說我要大膽鮮艷，但骨子裡要明確，竟然就給我這麼棒的簡報排版；最後一份由於資訊量大，所以採用了 Claude Design 預設的排版，雖然看了會膩，但是在資訊傳達上真的挺不錯的。

以前做簡報看到白白的投影片，就會覺得萬事起頭難，啟動成本心好累，做到後期又會很計較哪邊排版沒對齊，我還會特別去拉視覺輔助線，實在很浪費時間。

最瘋狂的年代，我是用 Illustrator 做簡報，Illustrator 縮寫也是 Ai。要說你有多猛，我可以很自豪的說我用 Ai 做簡報，夠 hardcore 了吧。至於 Gamma 我真的沒用過，應該是 Z 世代的東西了。

但現在有了 Claude Design，這些東西都可以事先設定好，然後直出，有夠颯爽。等於是在標準化的過程中，局部增添創意，就不會有萬丈高樓平地起的壓力。

而且最爽的是 Claude Design 可以直接在網頁介面修改字！甚至是用白板筆圈起來說這邊要改成怎樣等等，簡直就是慣老闆業主的福音。這些不是過去 Claude Chat 或 Claude Code 可以辦到的事情，實在是偉大的產品。

所以我現在都是把大量前置資料、順序想過一輪後請 Agent 整理完，交接給 Claude Design，生完以後再交接回我的 Agent，放到我的網址連結，效率之高，實在令我敬畏。

至於 AI 味，那種簡單的問題，自己過一遍，一下就修掉了。

所以我現在也不弄 PDF、pptx、key 這些檔案了，一律做成網頁版（html基底），甚至來事前對齊簡報也這樣辦，過去的人可能會覺得我很浪費，整個簡報製作思維都不一樣了。

＊

但我自己自評最扯的案例是這個。

上週由於太忙，需要做一個線上英文演講，但我直到演講前 90 分鐘才有空開始準備。

事先是在備忘錄寫了一些零散的想法，於是我就對著錄音機，瞪著這些想法，用中文先講了一遍。然後請 Agent 幫我潤演講稿、轉寫成英文、尋找對應的 reference、然後自動化的製作簡報內文。

然後我再丟給 Claude Design，我跟他說我要大膽鮮艷的風格，他馬上就做出來了，而且著實令人滿意。

我甚至還有時間請他完成網頁動畫特效。

演講也就順利結束了，我就是開著我的部落格網址連結，用生成的簡報把它講完。這次極限壓縮在 90 分鐘的前置準備，實在是破紀錄。

＊

Takeaway

如果你掌握高度專業的設計、排版、前端技能，用 Claude Design 絕對可以高速完成 70-80 分左右的成品，我甚至拿本來應該要是網頁端的「按鈕元件」都拿來放在簡報裡面，有夠快樂。

這還只是做簡報，沒用到 Claude Design 的其他功能。

也因此，我可以花大量的時間沈浸在資料海洋，以及心智的大綱草擬過程裡面，這是我做簡報最快樂的過程，如果知道後面的排版、與簡報製作過程可以如此高效且穩定，我會更樂意起心動念做簡報。

用語音來轉簡報這檔事我是第一次做，結果效果如此之好，以後我應該會更依賴這種工作流。

我本來就不喜歡放圖片到簡報裡面，所以 Claude Design 用各種符號、色塊來進行簡報製作，剛好對了我的胃口。

把簡報開源、放到自己的網址，某種程度上也是一種成長足跡的紀錄，對於學術生涯、tracking record、還是各種潛在的抄襲證明，這種時間戳記的效益非常順理成章。

目前累積了五份簡報，應該很快就可以做年度九宮格了。

我很開心過去培養的美感，現在解放後又可以再次實踐，人生不虛此行。

要這樣快樂玩，至少要 100 美金的 Claude Max 方案。我現在是 OpenAI 與 Claude 各 100，非常夠用。
