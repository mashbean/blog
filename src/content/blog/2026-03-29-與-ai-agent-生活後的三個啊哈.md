仔細記錄一下這兩個月與 AI Agent 協作的雜感。

這兩個月有三個「啊哈！」時刻，分別是「我的下載項目竟然整理好了！」、「我竟然可以一邊走路一邊動嘴工作！」、以及「我竟然可以慢下來，事情卻好好做好！」。

寫這篇文的目標不是說我變成了一個多厲害的人，但由於深刻地改變了自己的工作型態，忽然要我說真正改變了什麼，又有點複雜，於是值得好好想想之後，記錄下來。

與其說我學會了 AI 什麼，能完成什麼很厲害的事，不如說 AI 「身教」了我怎麼去認清自己。而且這兩個月不同階段的變化，真的很像剝筍子，越裡面越誠實地面對自己，包含天賦與劣根性。

到今年二月過年以前，我都是使用 ChatGPT 生活，固定一個月訂閱費 20 美金，預設模型都是 thinking，在農忙時節或是有研究經費時，會拉高到 200 美金，把 thinking 再拉到 Pro 模型。

在此之前，對於河道上 AI hype 與新名詞，老實說是有點抗拒，而且過去兩三個月另有其他實踐題目，所以沒有太關心。

直到今年過年的尾巴，手癢下載了 Codex，也就是 ChatGPT 的 coding 版，想說本來就有訂閱 ChatGPT，因此不用多付錢，不妨來試試看。結果整個日子開始天翻地覆了起來。我知道多數人是先從 Claude Code 開始。

原來給予電腦端搜尋與建置權限的 AI Agent 是這麼一回事。我的下載項目、Google Drive、Dropbox 等等的陳年老資料們，在彈指之間都被整理得一乾二淨。

這是我的第一個 Aha moment，也讓我知道 ChatGPT 與 Codex 即使共享了同一個大型語言模型，但完全是不同概念的服務。後來推坑別人，都是用「資料夾整理」這種最最簡單的 Aha，包含我爸也一頭栽了進來。

＊

這是我第一次的多巴胺爆發，茶不思、飯不想，直到急性腸胃炎為止。這個階段我最想探討的是一種「虛偽的全能感」，這種衝擊力或許與暈船、初戀、勝利的美味神似。

生而為人，用了 Agent，我似乎手腳、心智都延伸了，這種「實感」讓人感覺無所不能，或稍稍能多做一些以前無法想像的事，但事實往往不是如此。待多巴胺平復之後，就非常清楚一個想法的落實遠非動動嘴巴就能完成，即使現在嘴巴也可以搓出幾千行程式碼，仍然一樣。

有些資深工程師不齒 Vibe 仔，無非是因為這種因全能感而生的外顯行為。不過另一方面，我向來關注「啟發能動性」的任何案例，這次 Agent hype 顯然觸發了許多個體的能動性。即使最後重複造了車輪、弄出了一坨沒有完成的電子玩具半成品，但這種 Maker、DIY 的精神是真實的。

每個人都有自己企圖心上的局限性，我們看到行銷人做了自動化行銷工具，非營利人降低了自己過去不得不的重複勞動，自動化愛好者就如同當時 slack、notion 出世時用極端 J 人的方式實踐自己的生活，工程師顯著降低自己的工時但默默不語。

我想講的是，玩了 Agent 的人，讓我們看到了他「更好的版本」的自己，這是顯而易見，因為透過機器，人們更易於，也更樂於展示出更好的自己。這是一個人感受到無所不能之後，必然的實踐策略。好吧，推論有點薄弱，但我還沒看到玩了 Agent 之後把自己弄得更廢的案例。

這時候難免會出現「文人相輕」，先進者嘲笑另一群人的「野人獻曝」，這時我都說「他們眼中好的自己與你眼中的好版本，可能本來就不一樣，所以就用祝福目送他的進步吧」。你會看到異溫層，是因為演算法，相輕也沒啥用。再不濟，大家也在不知不覺中多了些開發知識，或問問題的能力。

我自己也搞了些小東西，做了自己的部落格、建立了議題研究上的自動化流程、搞定了組織間一些提升效率的工具，比如會議錄音自動轉會議記錄文件，這真的無比快樂。

其中當然經歷過自以為自己厲害可以自幹小功能的歷程，結果沒兩週就有人，往往是官方，有了更好的解決方案，由官方逼死同人。我後來體認到自己的價值不是去解決這些低垂的問題，而是有耐心地躺平，等待低垂的果實自己長出來。

當然隨之而來也出現不少不嘻嘻的事，錯誤、幻覺容易因自己的開發基底不好而冒出來。不過這些不會的事，反倒讓我開心，我真是感謝自己過去沒有轉職成純工程師，現在這些不會，每天問一百個問題都可以馬上解決。

五年前，我從醫師轉職，在二轉的技能樹上封閉了念到一半的台大研究所與 coding 技能，全面轉向狂點出一張嘴與抽象規劃的技能。到後來拿了資安證照又跑了幾輪大型資訊採購案，我真是感激命運讓我走上了最好的繞遠路。

我隱隱覺得到這年紀還敢於白目提出大哉問、敢碰複雜問題、並且勇於屢敗屢戰的人，是這個時代最抽象，但也最易於被捧在手心上的人。我把它寫到了最近的獎學金申請，哈哈。這些技能或傾向是教科書沒教的，是在不同領域的前線作戰才會獲得的。

前陣子與資深工程師朋友聊天，我原本以為碰了 AI Agent，人會藝高而膽大，工程師或許更具有優勢。但朋友說即使是工程師也不一定，許多人有其想像上的極限，而且更有執行上的極限。因此這與前面段落提到的「更好的版本的自己」的自我實踐，就吻合了。不是每個人的理想都是屢敗屢戰，只是屢敗屢戰，更適合與 AI Agent 共舞。

＊

玩了 Codex 過兩週，我清空了整台電腦，裝了龍蝦 OpenClaw，痛苦指數變高，但是出現了第二個 Aha moment。我發現我竟然可以走在路上，喊家裡的龍蝦幹活，而且工作流並不會比較慢。

我步入了健康的人生，每天在外面走一萬步。我從迴龍站走到亞東醫院站，從萬華走到板橋，從民生社區走到信義區。我一邊與龍蝦共事做正事，一邊練習說英文，一邊與同事語音開會。

我幾乎進入了純語音工作的時代，這真的是我夢寐以求的。我的咬字變得清晰、指令變得更準確、我更能習慣聽自己的聲音。我把龍蝦工作回報灌了我自己的 deepfake 語音，彷彿在與另一個自己共事。

我的工作工具變成了一支 iPhone 加一對 AirPods Pro，甚至連行動電源都不帶了，因為 ChargeSPOT 很方便。事實上這個工作方式的改變，是向 Vitalik 學習的。他說他喜歡一邊走路一邊受訪或開會，因為比坐在電腦前面腦子還要清楚，試了幾次發現還真的效果絕倫。

而且我體重瘦了好多，皮克敏升了好幾等。

非常希望 Claude Dispatch 的功能也真的這麼方便，或者 iOS 27 之類的蘋果原生生態系可以這樣。龍蝦有點土炮，家裡放一台電腦當伺服器有點不夠優雅，而且顯然有些功能可以更好，但這真的改變了我的工作模式，我相信這是 Siri 本來想要達到的狀態。

但接下來痛苦的事情多了很多。一開始為圖一樂而做的不少專案，終於迎來了版本控制與資料結構上的崩潰，因為龍蝦與我的工作電腦是兩台。如果要做到可以順利協作，就需要妥善、乾淨且同步的管理方式。我花了好一番力氣才把 git 重新梳理好，並且串上了 GitHub Project 的看板，還裝了協霆開發的 Claude 自動回覆。對的，又手癢刷了 Claude。

花這麼長一段描述雙機 N 個 Agent 協作，是因為這真實改變了我的工作流程。在 Codex 時代，或許是一種半人馬模式，或者是我因學會開車可以更快到遠方，但多了不同體系的 Agent 之後，我忽然發現這已經不是半人馬，而是一種接近蜂群或軍團的協作狀態，而我才是整個蜂群裡面的瓶頸點。

因為我才是知道自己想要什麼的人，機器即使能幾乎自動化互動、展延，要嘛回來問我是不是這樣，要嘛走太遠走成不是我要的樣子。在這個階段我真正清楚，清晰明確的規劃與驗收，還有清楚的自動化流程管理，也就是手搓的事，事不過三，威力多麼強大。

＊

這讓我進入第三階段，生產力真正暴增的時代。在這之前我都覺得是開開心心 DIY 圖一樂。我的日常工作在還沒有 AI Agent 來臨時，其實已經是高度創造性、勞心大於勞力、勞作感比例下降到最低的狀態，這已經是我的理想工作條件。我沒想到再加上 AI Agent，我還可以再榨出更多空間，用來提升創造力與解決重要問題。

我的工作廣義來說，是生產具備區隔性的洞見，無論類別是學術研究、商務分析、還是公共事務，用以獲取資源後，妥善使用資源。聽起來好像廢話 XD。

這些工作看起來不同領域，但工作流程實在神似，而且最近太忙，每天都要提交一到兩個完整的報告。在反覆迭代下，品質竟然超越純手寫，我實則變成了天馬行空的慣老闆與把關評估可行性的總編輯的複合體，最終形成一個完美的閉環。

這一切背後都是夠好的模型，謝謝我自己願意課金快一萬，但超級划算。還有夠好的迭代機制，謝謝龍蝦給我的學習歷程，後來回推到 Codex、Claude 效果更好。以及夠好的版本控制，最後乾脆三壁 Agent 合一，使用同一套標準流程。

在最忙的時候，我甚至可以開大絕，一次開十個 Deep Research 同步研究，每次跑個半小時到一小時，然後自動地將結果反覆整合精練，再重新投回生產流程之中。但副作用就是讓自己更沒耐心去好好看完所有半成品內容，而是想要更高維的方式去碾壓低階錯誤。

這讓我體認到，真的不用求快，只為了圖一個不上不下又害怕有幻覺的答案。超級長的思考鏈以及妥善的查核機制讓我願意多等等，畢竟健康長期的工作步調，當然不是靠多巴胺來衝一波。好的 work-life balance，是讓血壓、血糖維持穩定，也讓生產結果維持高品質，更讓自己有餘裕去思索每個人都在乎，但沒人敢面對的題目。如果還能在外面走路，就實在是再好不過了。

反正 AI Agent 會給我令人驚奇的思路。

＊

不知不覺把雜感寫了太長，花了點時間梳理了自己與 AI Agent 協作的三個「啊哈！」階段。

最後的最後是自己覺得過程中很重要的助力。第一個是有真人導師真的很重要，我的導師之一是林協霆，哪怕只是丟給我一個 repo，都讓我少走了很多冤枉路。自己當然花時間可以解決，但這種省力感真的很讚。

第二是有意識地創造 AI 導師，讓自己可以跳脫幻覺迷霧。AI 導師不只督導我自己，也督導我的 AI Agent 們，可以每天後設地三省吾身，自我強化。

第三是抽象地圖的思考能力真的好讚好爽好重要，知道自己迷航在哪個專案的哪個步驟中，不只可以把自己撈起來，還可以把 Agent 也撈起來。不知道要怎麼培養，但是清晰的規劃、版本控制應該是前提條件。

最近同事們紛紛做了自己的 AI Agent，當然會互相分享，每個人產生的 Agent 風格都差很多，某種程度上可能又吻合了前面所說的自己的延伸。

如果透過 Agent 更清楚了解自己是誰，或許就不會焦慮未來世界的模樣，而是迫不及待地把自己再次投入回真實世界，好好生活，好好工作。
