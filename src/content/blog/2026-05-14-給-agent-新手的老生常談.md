連續四天不同朋友們來我家玩，不知不覺都變成了 Agent 學習會。我實在是很享受這種幾乎是一對一的交流過程，兼具致用兼思辨，彷彿是過去學長教我打中央靜脈導管，但這時代的導管可以通往八方。由於這些朋友專業與工作各異，拋出來的問題還有與 Agent 互動的方式都不一樣，很是過癮！

我也不是用的多厲害的傢伙，但從結果論還真的做出了一些想做很久但沒時間完成的專案。此外也好在不用賣課，我最樂見也最快樂的過程是看到具有能動性的好朋友們藉著 Agent 產生更高的能動性，完成有意思的專案。畢竟我自己解放了自己許多時間，多出來的時間又投入更多自己想做的事情，我想我的朋友們也大都是這種個性。

因此整理了一些很老套但我覺得很有效的 Agent 老生常談。如果你還沒有進入 Claude Code 或 Codex 的世界，看完以下拋磚引玉的想法，真的安裝來玩一下，我會很期待世界上又有更多好傢伙做出了有意思的東西。

一、Claude Code 與 Codex 名字取得很糟！實際上不用會寫程式也可以把這些 Agent 工具玩起來，我自己就是不寫 code 的人。而且我隱隱覺得沒包袱的人可能更容易有新的使用模式。連我爸都跳下來玩的不亦樂乎了。

二、如果你在 ChatGPT 問了或做了重複三次一樣的事情，然後隱隱感到厭倦，那這件事就很值得給 Agent 做，因為 Agent 會幫你把流程標準化，每次走同一套又快又好，不用挑戰 LLM 的才華。比如一鍵錄音檔轉會議記錄、研究素材分析、部落格上稿，這些是我每天用到爛的流程，省掉很多時間。

三、慢慢來比較快，這點適用於 Agent 或 Chat，這說從狸貓朋朋圈學到的洞見。當我們在處理困難的問題，越重的模型往往令人滿意，不過推理速度會慢，不過我們何必趕時間呢。最近 ChatGPT 手機 App 也支援 thinking-extended 或 pro-extended 了，記得用用看。（而且只有 ChatGPT 能 Deep Research，Agent 不能讓我至今理解不能，還是其實有方法可以！）

四、如果做出了一個好工具（或拷貝別人的好工具），又每天都會用到的話，每天給 Agent 一些建議去迭代工具，會越來越好用。比如我建立了自己的研究流水線，每天都有快萬字的好文，最近品質已經慢慢穩定下來了，而且行文過程中，會自動用五種推理流程的辯證，並且以實證精神來抽掉薄弱的上下文，這種東西很難一天就達標，但每天施肥翻土，看看它進步，自己也進步，是很快樂的。

五、不要再去管河道上的 AI 文了，如果因為賭爛那些文然後不去用 Agent，那真的是很可惜，這兩者幾乎是不同世代的工具。會用 AI 生文章的人，不一定知道怎麼善用 Agent 。與其去在意、計較「這不是…，而不是…。」，真的別浪費時間去看那些 slop，不如去與 agent 討論合成內容的推論是否有毛病，這對自我能力的提升也很有幫助。

六、一樣是老生常談吧，很會不恥下問的人特別能大幅度縮短學習的迴圈，他們能與 Agent 共同成長；很有特定品味與洞見的人也很適合使用 Agent，因為他們特別能在關鍵環節生產出最有價值的內容（亦即不關鍵的環節自動化也無妨，除非你喜歡在這種手工的環境中獲得靈感）；手握大量素材的人也非常適合，因為分析素材就是 Agent 的強項，有好的方法論就更棒了。

大概就醬，野人獻曝一下。
