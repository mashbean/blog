看起來是有趣的（公部門）工作，或許能對台灣 web3 或加密貨幣環境產生一點影響？因此推推。

以下原文照貼：

// 證期局聘用副研究員職缺，
// 公告期間113年3月29日至113年4月16日
// 金融監督管理委員會證券期貨局

// 工作項目

// 一、辦理具金融投資或支付性質之虛擬通貨平台及交易業務事業，其業務與洗錢防制及打擊資恐之管理、企劃、研究、發展與資料蒐集事項。
// 二、辦理國內外金融監理及服務等法規之蒐集、整理及編譯事項。
// 三、證券及期貨市場監督與管理等相關業務。
// 四、其他臨時交辦事項。

// 月支報酬:每月新台幣68,857元起支。

（另外但書四尤其有趣）

// 四、依據本局員工自律規範，本局同仁、配偶或未成年子女不得購買股票及其他金融商品，到職前(後)持有者，原則於一年處分完畢。請報名人員務須留意。
