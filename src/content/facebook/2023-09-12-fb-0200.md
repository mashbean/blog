這是今年 W3C（全球資訊網路協會）年度大會 TPAC（全名為技術大會與諮詢委員會）第一天，我最印象深刻的環節，在這場 Solid Community Group（Solid 社群小組）討論中，社群成員討論 Solid Protocol 與隨附章程的工作進度，李爵士當然也出席了他一手創辦的專案與大家閒話家常。

## 觀察

提姆．柏內茲．李爵士先發明了網路（www）與網頁及瀏覽器，然後在網路上發起全球資訊網協會（World Wide Web Consortium, W3C），以治理各式網路標準，如html、css、xml 等等，然後這幾年又在 W3C 裏面發起了 Solid 社群小組，意圖使網際網路導回最初的模樣—去中心、互通且不分裂的網路。

混 web3 的人應該聽說過， Web3.0 最早的定義是語意網路（Semantic Web），而非區塊鏈爾爾。確實李爵士在今天的討論會也提了一樣的事，畢竟這是他很久以前提出的，目前全球針對這個歧異語，初步共識是前者為 Web3.0，後者為 web3。Web3.0 是一個更大的去中心互通敘事，不一定是區塊鏈或分散式帳本技術衍生的網路社會。而語意網路最近使用的人變少了，取而代之的是關聯資料（Linked Data, LiD），而 Solid 便是社交關聯資料（Social Linked Data）的縮寫。

李爵士的人設很像台大廖世偉教授（如果大家認識他的話），都是短褲配夾腳拖的天才，然後思考速度遠高於講出來的話，所以聽起來像沙拉拼盤。他說 Web1.0 透過 HTTP、HTML、CSS 與 RDF 等協議支援，由資料組合而成靜態網路。而 Web 2.0 新增了 JavaScript 與 web APIs 等功能，讓互動的網頁應用程式成為可能。但這些應用程式通常典型的架構是在伺服器與 app 之間溝通，如 Facebook。Web2.0 的網頁資訊是不可互通的，如使用者資料。而有了 Solid 協定，你可以用 Solid 登入任何一個服務，如 Google。

而 Web3.0 意圖將這個互動性還給使用者，築牆自保，再談互通，而非將資料暴露於豺狼虎豹之中。基本上我很相信姓名學，好的命名（迷因）會讓一個好發明聲名遠播，因此姑且稱 Solid Protocol 為「固態協議」吧。請注意，這裡的 Web3.0 完全沒有代幣經濟（tokenomics，右傾）或去中心治理（de-governance，左傾）等酷炫玩意兒，是純技術層的設計。

## 想法

固態協議基本上分成三個層次：關聯資料格式（Linked Data, LiD）、身份（webID）與倉庫／保險箱（Pod）。

在固態的理想世界中，你的所有資料是存在保險箱裡面的，你可以自己弄一個保險箱，也可以用別人的保險箱服務。而這些保險箱都可以用 webID 來打開與控制別人能否打開。這與臉書或 Google 完全不一樣了，因為資料是在自己身上的，別人只能看到「資料的資料」，也就是關聯資料（LiD or metadata）在外面飄。直到使用者同意臉書使用資料，臉書才能使用真實的個人資料，並讓個人繼續在保險箱裡面添入資料。

這與現在常見的網路使用方式完全不同。因為資料與個人身份是由自己掌管的，一言不合就可以遷移到其他服務上，而不是被單一服務商給綁架。其實目前已有懷著類似理想的人進行不同工作，如社交平台互通的 Activity Pub 或 Fediverse、去中心身份（Decentralised Identity）與去中心社會（DeSoc）（該流派也提出以靈魂綁定代幣（SBT）處理社交圖譜與社會信用，如 zkSBT），或歐盟三法門 eIDAS（電子身份與信用服務）EUDI（歐盟數位身分錢包服務）與 EBSI（歐盟區塊鏈基礎架構）。上述前兩者在 W3C 也都有小組在嘗試。

目前 Solid CG（社群組）已經寫好新章程，即將再下一城升格為 Solid WG（工作組），讓我們繼續看下去這個充滿學術風味的 Web3.0，能否真的保護人類的數位身分自主權、資料民主與資料聯盟。 

此外，該會議中，不同政府紛紛表示已經使用 Solid 開源協議處理自家資料儲存服務，李爵士也是英國政府數位化的重要推手，因此讓我們來猜猜看 Solid 或類似的去中心協議能否在台灣慢慢落地生根。
