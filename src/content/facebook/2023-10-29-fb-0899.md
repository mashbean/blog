我覺得要分成兩個軸向來看：
1. 一個人一天有多少 token
2. 一個人休眠狀態是停機，還是持續耗能

如果一個人的 token 很多，那他下班就還會有餘力做更多事，家事、娛樂、第二份工作等等。如果一個人的 token 在工作就被耗盡，那他只能舉債先用掉隔天的 token，這導致最後只會 burnout。（注意，每個人消耗 token 的方式不一樣，比如我的腦力 token 偏多，但體力 token 與社交 token 都很爛）。

第二部分，下班後的人如果沒有 token，那可能產生「反 token」，對撞會炸掉。下班後如果有 token，他如果還在煩惱上班的事情，那就會虛耗掉剩餘 token，這等於是沒有在下班，比下班以後還在加班還慘，因為加班至少還有生產力。

所以下班不要煩惱，留給上班，上班也不要煩惱，留給下班，這樣就永遠不用煩惱了（煩惱的量化寬鬆）（大誤）

一切離苦得樂。
