## 背景

![fb-0263-1](/images/facebook/fb-0263/10216406728800168.jpg)

《台灣第一間美術館，持有 NFT 展品可無限次看展》

不好意思，又要用標題騙大家進來看文章了。

想與大家分享我昨天怎麼過的。這是我第一次覺得 NFT 真真在在入侵了我的生活，我相信 NFT 接下來還會入侵更多人的生活。

＊

早上接受採訪，對於內向者如我，受訪總會扭捏不自在。但一見面這位記者朋友馬上秀出左手的 apple watch，封面竟是 TezDozen 川貝母猴！這彷彿某種地下組織的身份印記。當然我也秀出我的 iphone 7 川貝母雞桌布尬一波（就是我現在的頭像）。

這是一種神奇的時刻。

PFP 塑造了全新的社群，它並非是一個以興趣、專業、社會身份為目的的團體，團體成員在真實世界是如字面意義的百工百業。購買 NFT 的消費者通常具有一定消費能力，而這些人早已卡在社會體制中。

而這些人正在尋找結構共振的機會。

或許這是一種全新的第三場所，自外於住家、工作地點，也不是咖啡館，而是純虛擬的元宇宙客廳。

＊

我原先並不是一個外向廣結善緣的人。

但是在網路空間可以很健談，而 PFP NFT 創造了出身份認同的載體。剛好讓我原先沒有察覺的外向落地回到現實。

## 觀察

事實上，我最近的社交網絡全都是與從 NFT 開始。

＊

昨天另一個電視節目採訪，我們在數位藝術中心與三明治工的小雪 Jo Lin Hsieh討論公益型態的 NFT 的實踐；又在前一天，我們在大稻埕的打開當代藝術站，與羅仕東討論 NFT 藝術品收藏過程中，帶來與海內外創作者混熟的日常，彷彿元宇宙駐村行動。

會認識以上這些新朋友，都是因 NFT 收藏過程而認識，最近甚至成立了新的策展團體要來做很前沿的 NFT 實體展覽。

＊

最酷的事情是晚上。

台北當代藝術館（MoCA Taipei）新展覽開幕，新展覽名為「蓋婭：基因、演算、智能設計與自動機＿幻我；它境」，由沈伯丞老師策展。

這是台灣第一個藝術展覽，你可以收藏展覽 NFT，來無限次逛展。（這個賦能夠酷了吧，而且價格很便宜）

這個展覽 NFT 名為「蓋婭__演算生成」，是由 黃新 創作。NFT 本身是一個演算藝術作品，每一個持有者會生成不同的 NFT，端看你的錢包地址。

當然，這個展本身也有展覽 NFT，包含 Aluan Wang、黃新的 Tezos NFT 作品。除此之外竟然還有 Matt Deslaurier 的傳奇子午線，整個生成藝術、加密藝術、互動科技藝術，因為 NFT 這個媒介（media）產生了質變。

阿亂的 GeoPunk，用加密的方式包裹國界與地緣政治問題，只有真正的持有者可以解開世界各地政治訴求的謎團，這是 NFT 的加密；Matt 用程式碼與隨機性，扮演上帝開創數位山河，這是 NFT 的生成；黃新的 Not Without You 將 NFT 持有者的名字與頭像投影在展覽牆面上，擁有越多的份數，將產生越大的佔領，這是 NFT 的互動。

＊

最後一定要特別書寫黃新的 Blooming。

## 想法

這是一件實時反應 Tezos NFT 交易量的互動作品，只要有交易， NFT 就會放煙火。

昨晚導覽時，黃新現場買了一張 80 XTZ（新台幣一萬元左右）的阿亂 GeoPunk 展覽作品。Blooming 這件作品馬上放出一顆超大的煙火。震撼現場觀眾，令我印象深刻。

＊

回過頭來看，NFT 是不是煙火式的發明？我認為不是。

NFT 竟可以是「美術館生成式作品 with 無限通行證」。本身有票券屬性又是藝術作品，這種多重性，顛覆了我的傳統想像，誰說門票一定是門票、作品一定是作品、紀念品只能是文創商品，這些概念，NFT 把它們全混在一起。

我最好這味兒，或許大家必須開始熟悉這種複雜性。

＊

當代館都開始進行這麼性感的嘗試了，台灣真是走在很前面。

當然「蓋婭」展覽除了 NFT 作品還有許多對於科技、生物的作品，非常值得一看。

感謝 沈伯丞 駱駱 老師們帶來如此美麗的展覽。

＊

這是我昨天的生活，NFT 佔滿了每一分每一秒，分享給大家。
